# Gimmick Bench

A benchmark for the computers at Gimmick that measures them doing real motion design
work in **After Effects** and **Cinema 4D**, so we can tell which machines slow
production down and which ones to replace or upgrade first.

It does not run synthetic CPU or GPU tests. Every number comes from After Effects
or Cinema 4D rendering, evaluating or loading the same generated projects on every
machine.

| | |
| --- | --- |
| Platforms | macOS (Apple Silicon and Intel) and Windows |
| Apps | After Effects 2025 or later, Cinema 4D 2024 or later, Octane (optional, scored separately) |
| Run time | About 2 hours (full), about 45 minutes (quick) |
| Results | One raw JSON file per run, saved locally and sent to the studio Google Sheet |
| Dependencies | Python 3.9+ (standard library only) |

**Status:** Phase 2 (benchmark engine). Scoring (Phase 3) and the office dashboard
(Phase 4) come next. The engine has not been run against real After Effects or
Cinema 4D installs yet; see [docs/first-real-run.md](docs/first-real-run.md).

## Running it

1. Copy this folder to the computer (or `git clone` it).
2. Double-click **`launcher/Gimmick Bench.command`** (Mac) or **`launcher/Gimmick Bench.bat`** (Windows).
3. Check the detected hardware and apps, set the computer's name and main use, then click **Run Full Benchmark**.
4. Leave the computer alone until it finishes. The result is saved in `~/GimmickBench/results/` and sent to the studio sheet when it is set up.

Command line equivalent:

```
python3 -m gimmick_bench detect             # what hardware and apps were found
python3 -m gimmick_bench run                # full run
python3 -m gimmick_bench run --quick        # about 45 minutes
python3 -m gimmick_bench run --suite ae     # only After Effects (also: c4d, gpu, multitask)
python3 -m gimmick_bench run --ae-version 2025 --c4d-version 2024
python3 -m gimmick_bench list               # every test
```

`--simulate` (or `?demo=1` in the launcher) produces made-up numbers for trying the
tool without the apps. Those results are marked as simulated and are never uploaded.

## One-time setup per computer

- **After Effects:** launch it once so it creates its preferences. The benchmark turns on *Allow Scripts to Write Files and Access Network* itself (a backup of the preferences file is kept next to it).
- **Mac only:** nothing to allow. The benchmark puts a small launcher script (`gimmick_bench_launcher.jsx`) in After Effects'
  `Scripts/Startup` folder and starts AE with `open`, so no Automation permission is needed. Only if that folder
  cannot be written does it fall back to AppleScript, and macOS then asks once to let Terminal control After Effects.
  Scripts and footage are copied to `~/GimmickBench/bundle`, so AE never asks for access to the Desktop or Downloads.
- **Cinema 4D:** open `c4dpy` once from the Cinema 4D folder and sign in with the Maxon App, so the benchmark can run it without a login prompt.
- **Results sheet:** follow [sheets/README.md](sheets/README.md) once for the studio, then on each computer:
  `python3 -m gimmick_bench configure --sheet-url "<url>" --sheet-token "<token>"`.
- If After Effects is open when a run starts, the benchmark asks it to quit (it still asks about unsaved work).

## Repository layout

```
gimmick_bench/       runner, protocol, statistics, monitors, upload, launcher UI
  platform/          macOS and Windows hardware detection and monitoring
  apps/              After Effects and Cinema 4D drivers, install discovery
  suites/            test definitions (ae, c4d, multitask, simulated)
scripts/ae/          ExtendScript that builds and times the After Effects project
scripts/c4d/         c4dpy scripts that build and time the Cinema 4D scenes
assets/footage/      4K test footage and stills, with SHA256SUMS (generated by tools/make_footage.sh)
sheets/              Google Apps Script for the results sheet
launcher/            double-click launchers for Mac and Windows
tests/               unit tests: python3 -m unittest discover -s tests
```
